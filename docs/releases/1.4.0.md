## Smoother League of Legends gameplay

Set League of Legends to **Borderless** at your display’s resolution. GameEdge now lets the game draw directly while you play, without a continuous video mirror. When you switch to another app, a live background preview keeps the game visible; clicking the picture returns to the game and stops capture.

- Keeps cursor confinement and restores your normal monitor arrangement when you switch apps.
- Handles window-mode changes and temporary failures to read window information without unnecessarily switching capture paths.
- Prevents concurrent capture startup in the windowed compatibility mode.

**Upgrading from 1.3.0:** change LoL from Windowed to **Borderless**, and leave **Full resolution and background picture** enabled in GameEdge. The old windowed mirror remains available for compatibility, but can reduce fluidity.

Verified in a live training session on the development Mac, with the user confirming recovered smoothness. Background preview targets 30 fps and requires Accessibility and Screen Recording access. It uses a private macOS capture API; compatibility with other Mac and macOS configurations has not yet been verified. If that API is unavailable, native gameplay remains available without the background preview.

Universal build for Apple silicon and Intel, macOS 14 or later.
